Manual @importlollipop

Loading style.lcss and its imports…

This page has no rel="lollipop-stylesheet" link. JavaScript loads, compiles, and applies the stylesheet manually. 

@importlollipop "./var.lcss"

Manual loading code

const response = await fetch("./style.lcss");
const source = await response.text();

const compiler = new LollipopCSS();
const css = await compiler.compileAsync(source, {
    baseUrl: response.url
});

LollipopCSS.apply(css);
