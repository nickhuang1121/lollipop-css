Why LollipopCSS?

SCSS can already do all of this. That's not the problem.

The problem is that when I'm maintaining a large project, I'm too lazy to keep writing @mixin and @include over and over again.

So I made LollipopCSS.

Yes, I'm lazy. Very lazy. 🍭 I have better things to do — like eating McFlurries and lollipops. 🍦🍭

1. Write LollipopCSS

Define a value and a utility inside @lollipop, then use the utility by name.

@lollipop {
    pxMd 15px
    paddingMd padding pxMd
}

.card {
    paddingMd
}
.card-title {
    paddingMd
}

2. Get valid CSS

LollipopCSS resolves the reusable value and outputs standard CSS for the browser.

.card {
    padding: 15px;
}
.card-title {
    padding: 15px;
}

3. Apply it automatically

Use rel="lollipop-stylesheet" to load an LCSS file. By default, LollipopCSS compiles it and replaces the link with a generated <style> element in the document head. 

<link
    rel="lollipop-stylesheet"
    href="./style.lcss"
>
<script src="lollipop-css.js" defer></script>

4. Or export a CSS file

Need a standalone file? Set output to download. The same LCSS source will be compiled and downloaded as regular CSS. 

await LollipopCSS.load("./style.lcss", {
    output: "download",
    filename: "style.css"
});

5. Every loading method

Choose the smallest API that matches where your LCSS comes from.

Automatic external file

Best for normal browser usage. Imports are resolved automatically.

<link rel="lollipop-stylesheet"
      href="./style.lcss">
<script src="lollipop-css.js" defer></script>

JavaScript URL loading

Loads, compiles, resolves imports, and inserts a <style>.

await LollipopCSS.load("./style.lcss");

Inline LCSS

Useful for small styles without external imports.

<style type="text/lollipop">
@lollipop {
    pink #ffafcc
}
</style>

Compile a string

source is a JavaScript string containing raw LCSS, such as text from an editor, a textarea, or generated content. Use the synchronous compiler when that string has no imports. 

const source = `
@lollipop {
    pink #ffafcc
    BGpink background pink
}

.card {
    BGpink
}`;

const compiler = new LollipopCSS();
const css = compiler.compile(source);

Compile a string with imports

The base URL tells relative imports where to load from.

const css = await compiler.compileAsync(source, {
    baseUrl: response.url
});

Download compiled CSS

Compiles the URL and downloads the result as a regular file.

await LollipopCSS.load("./style.lcss", {
    output: "download",
    filename: "style.css"
});
